Local Setup Instructions (Windows)

1. Navigate to the project directory
   cd C:\Users\ajith\Downloads\model-rag\Ragora-v2

2. Remove existing virtual environment (if present)
   Remove-Item -Recurse -Force .venv

3. Create a new virtual environment using Python 3.12
   py -3.12 -m venv .venv

4. Activate the virtual environment
   .venv\Scripts\activate

5. Verify Python version
   python --version

The output must show Python 3.12.x

6. Install dependencies
   python -m pip install --upgrade pip
   python -m pip install -e .

7. Run the application
   python -m uvicorn src.multimodal_rag.api.app:app --reload --port 8002

8. Access the application
   http://127.0.0.1:8002/docs
